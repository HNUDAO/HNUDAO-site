# Suggested commands for HNUDAO-site
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build static site: `npm run build`
- Preview production build: `npm run preview`
- Show repo status: `git status --short`
- List files quickly on Windows PowerShell: `Get-ChildItem`
- Search text quickly: `rg "pattern" src`
- List tracked files quickly: `rg --files`
- Change directories in PowerShell: `Set-Location <path>`
- Show Node version: `node -v`
- Show npm version: `npm -v`
- pnpm is preferred if available, but current environment did not have pnpm installed.
