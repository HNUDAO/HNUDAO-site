# 04 Domain and DNS

## 当前推荐方案

推荐使用：

- 阿里云购买域名
- 阿里云管理 DNS
- Vercel 托管网站

这样做的优点是：

- 域名和托管职责清晰
- Vercel 对 Astro 静态站点支持较好
- 后续换届时便于分开管理域名和部署平台

## 阿里云域名如何解析到 Vercel

如果域名在阿里云购买，可以继续使用阿里云云解析 DNS。

在 Vercel 绑定域名后，Vercel 会提示你应该填写哪些解析记录。实际操作时始终以 Vercel 控制台显示为准。

## 常见记录配置

### 根域名 `@`

通常使用：

- `A` 记录

记录值：

- 以 Vercel 控制台给出的值为准

### `www` 子域名

通常使用：

- `CNAME` 记录

记录值：

- 以 Vercel 控制台给出的值为准

## A 记录和 CNAME 的区别

- `A` 记录
  把域名直接指向一个 IPv4 地址
- `CNAME`
  把域名指向另一个域名

在常见实践里：

- 根域名 `@` 更常见用 `A`
- `www` 更常见用 `CNAME`

## 在 Vercel 上绑定域名的步骤

1. 打开 Vercel 项目
2. 进入 `Settings`
3. 打开 `Domains`
4. 添加你的正式域名
5. 按照 Vercel 提示回到阿里云 DNS 配置记录
6. 等待解析生效
7. 回到 Vercel 确认域名已验证成功

## HTTPS 证书

域名成功解析并绑定到 Vercel 后：

- HTTPS 证书通常由 Vercel 自动申请
- 证书通常也由 Vercel 自动续期

一般不需要手动购买或上传证书。

## 国内访问说明

如果网站托管在 Vercel 或其他海外平台：

- 中国大陆用户通常可以访问
- 但访问速度和稳定性可能受网络环境影响
- 不同地区和运营商体验可能不同

## ICP 备案说明

如果网站不部署在中国大陆服务器，也不接入中国大陆 CDN，通常不会触发中国大陆服务器接入备案要求。

这不是规避监管，而是托管地点不同带来的常见合规差异。

## 什么时候通常需要备案

如果以后改用以下方案，通常需要重新确认备案要求：

- 阿里云中国大陆 ECS
- 阿里云 OSS 静态网站并接入大陆 CDN
- 腾讯云中国大陆服务器
- 其他中国大陆云厂商的大陆节点服务

## 域名交接建议

- 域名注册账号不要放在个人毕业后可能失联的邮箱下
- 优先使用协会长期控制的邮箱或组织账号
- 至少两名负责人应掌握域名平台登录和二次验证方式
- 交接时保留：
  域名到期时间、解析记录截图、管理员名单、控制台入口

## 绑定正式域名后别忘了改这些地方

- `astro.config.mjs` 中的 `site`
- `src/lib/site.ts` 中的 `siteUrl`
- `public/robots.txt` 里的 `Sitemap:` 行
- 如有外部资料或 README 中的站点地址，也同步更新

改动后跑一次 `npm run build`，确认产物里的 canonical、`og:url` 和 `sitemap-index.xml` 都换成了新域名。
